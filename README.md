# Atelier Pascale

Atelier Pascale is a full-stack e-commerce website designed to showcase lacquerware, fashion items, and art pieces.

The project was inspired by my family's business, which traditionally relied on word-of-mouth sales and had little online presence. This motivated me to create a modern website where the business can showcase its products and reach a wider audience online.

## Features

- Browse products across different categories
- View detailed product information and images
- Shopping cart functionality
- User authentication
- Order functionality
- Responsive design for desktop and mobile devices
- Admin features for managing the products, images and orders
- REST API connecting the frontend and backend

## Tech Stack

### Frontend

- React
- Vite
- Tailwind CSS
- React Router
- JavaScript

### Backend

- ASP.NET Core
- C#
- Entity Framework Core
- SQL Server
- JWT Authentication
- REST API

## Deployment

- **Frontend:** Vercel
- **Backend:** Microsoft Azure App Service

The React frontend is deployed through Vercel, while the ASP.NET Core backend is hosted on Azure App Service.
